## 📌 Executive Summary & Problem Statement

India accounts for approximately **11% of global road crash fatalities** despite having only **1% of the world’s vehicles**. Over **150,000 citizens lose their lives annually**, with 70%+ of drivers unable to accurately recognize mandatory Indian Road Congress (IRC) signage or navigate right-of-way rules. Simultaneously, Indian drivers pay upwards of **₹20,000 Crore in preventable traffic challans** every year due to unawareness of the Motor Vehicles Act (MVA 2019 Amendment) regulations.

**Sarthi** is an engineering-first, zero-barrier educational platform built to transform every learner into a confident, responsible, and challan-proof civilian. Built with radical simplicity, it teaches road regulations in **3-minute visual bursts**, replicates the official Ministry of Road Transport & Highways (**MoRTH STALL**) exam, issues verifiable QR-coded certificates, and protects drivers with an interactive statutory rights guide.

## 💎 Design Philosophy & Core Principles

1. **The Steve Jobs Bar (Radical Simplicity):**
   - **Zero Fake UI:** Every button, modal, toggle, calculation, and link is 100% operational.
   - **Zero Signup Wall:** Immediate utility without phone numbers, OTPs, or passwords.
   - **Tactile Polish:** Sub-millisecond response, haptic feedback, fluid transitions, and clear visual hierarchy.
2. **100% Offline-First & Privacy Preserving:**
   - Zero telemetry, zero external tracking, zero ads.
   - All 15 curriculum modules, 28+ IRC signs, quizzes, and certificate verification operate locally without network access.
3. **Pure SVG Vector Engine:**
   - 100% vector SVG rendering adhering strictly to IRC standards (Octagon Stop, Inverted Triangle Yield, circular regulatory prohibitions). No blurry raster graphics.
4. **Multilingual Inclusivity:**
   - Accessible in **12 Indian languages** (Hindi, Tamil, Telugu, Bengali, Marathi, Gujarati, Kannada, Malayalam, Punjabi, Odia, Assamese, and English) powered by native Web Speech API audio narration.
5. **Warm Dawn Palette:**
   - Saffron (`#FF6B35`), Deep Green (`#1B5E20`), Warm Off-White (`#FFF8F0`), and Night Charcoal (`#121417`) designed for effortless daylight and night readability.

### 1. 🚦 Bite-Sized Visual Lessons
- **3-Minute Micro-Learning:** Deconstructs complex road legalities into single-concept digestible steps.
- **Threat Scanner Alerts:** Highlights exact challan penalties (e.g., *₹1,000–₹5,000 under Section 119 MVA*) embedded directly into sign lessons.
- **Audio Speech Narration:** Multilingual voice reading powered by the browser's native Web Speech synthesis.

### 2. 🎯 Practice Arena & Quiz Hub
- **Topic-Wise Quizzes:** 15 specific topic evaluations covering Mandatory Signs, Cautionary Signs, Road Markings, Right of Way, and Police Encounters.
- **Daily 5-Question Sprint:** Randomized rapid assessment testing road instincts across diverse categories.
- **Fairness Ledger & Feedback:** Instant correct/incorrect highlighting, reason explanations, and mistake streak recovery modes.

### 3. 📚 IRC Traffic Signs & Road Markings Encyclopedia
- **Indian Road Congress Standards:** Mandatory (circular/octagon), Cautionary (triangular), Informatory (rectangular), road markings (solid/broken white/yellow lines), and traffic signal phases.
- **Live Search & Filter:** Instant instantaneous lookup by keyword (*"Speed", "Overtaking", "Stop", "Hospital"*).
- **Interactive Modals:** Detailed views detailing shape rationale, legal implications, and fines.

### 4. 🏛️ MoRTH STALL Mock Test Simulation
- **Official Exam Replication:** Mirrors the layout, structure, and timing of the Parivahan Sarathi STALL (*Screen Test for All Learners License*) system.
- **Official 15-Minute Countdown:** Real-time countdown timer with automated submission at 00:00.
- **State-Specific Thresholds:** Automatically adjusts passing scores according to state regulations (e.g., Karnataka/Delhi: 10/15, Gujarat: 11/15, Kerala: 12/15).
- **AI Camera Proctoring Simulator:** Simulates facial vigilance / presence monitoring matching Karnataka SmartLock RTO standards.
- **Comprehensive Review Mode:** Detailed question-by-question breakdown analyzing missed choices and legal explanations.

### 5. 🏆 Official Sarthi Certificate of Competency
- **Cryptographic Identifier:** Auto-generates unique, serialized IDs (`SAR-YYYY-XXXXXX`).
- **Dynamic QR Code:** Scannable vector QR code embedding verification URLs.
- **Print & PDF Optimization:** CSS print isolation stylesheets ensuring crisp single-page physical certificate generation.
- **Social Sharing:** One-click WhatsApp status and direct link copy.

### 6. 🏛️ Government RTO Verification Web Portal
- **Inspector Tool:** Independent verification terminal for Motor Vehicle Inspectors to validate candidate certificates.
- **Registry Lookup:** Instant authentication verifying candidate name, state jurisdiction, test score, vehicle category, and timestamp.

### 7. 🛡️ Challan-Proof Module & Driver Rights Guide
- **Offence Directory:** Top 10 high-frequency violations under Motor Vehicles Act (Helmets, Seatbelts, PUCC, Red Lights, Mobile Usage).
- **Interactive Fine Calculator:** Interactive liability calculator showing monetary exposure and savings through compliance.
- **Section 130 Driver Rights:** Legal guidance on Officer Rank mandates (SI rank and above), illegal key-snatching prohibitions, DigiLocker validity, and electronic e-challan receipts.

### 8. 👤 Profile, Data Portability & Settings
- **Competence Badges:** Unlocks milestone achievements (*First Step, 5-Day Streak, RTO-Ready, Sign Master, Challan-Proof, Flawless Driver*).
- **Local-First Data Portability:** 100% JSON backup export and restore without cloud accounts.
- **Progress Reset:** Safe reset mechanism returning the application to initial onboarding.

## ⚡ Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher)
- **npm** (v9.0.0 or higher) or **bun** / **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/sarthi-road-safety.git
   cd sarthi-road-safety
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:3000`.

4. **Verify TypeScript compilation & code quality:**
   ```bash
   npm run lint
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
   The optimized production artifacts will be generated in `/dist`.

## 💡 Engineering Highlights for Technical Evaluators

- **Zero-Dependency Vector System:** Rather than loading 30+ external raster images, all signs are built as programmatic vector SVGs (`TrafficSignSvg.tsx`) with strict IRC proportional geometry, eliminating network latency and asset pop-in.
- **Local-First Synchronization Engine:** Profile state, streaks, test history, and certificates persist reliably to `localStorage` with error boundaries and data backup/import capabilities.
- **Accessible State Machine:** Controlled navigation flow (`home` → `lesson` → `quiz` → `mock_test` → `certificate` → `verify`) with memory of return routes.
- **Print Optimization:** Embedded `@media print` rules isolate the certificate during browser print commands (`Ctrl/Cmd + P`), cleanly eliminating navigation bars and action controls.
- **Defensive Error Handling:** Built-in fallbacks for missing speech synthesis voices, offline network detection via browser events, and safe clipboard API copy fallbacks.
